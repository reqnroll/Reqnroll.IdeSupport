# Welcome to Reqnroll for VS Code

Reqnroll brings **Gherkin / BDD support** to Visual Studio Code: syntax
highlighting, diagnostics, step completion, navigation between `.feature`
steps and their C# bindings, refactoring, and more — powered by the Reqnroll
LSP server.

This extension is a **Preview**. The full, up-to-date documentation lives on
the Reqnroll website — the links below take you straight to the relevant
pages.

## Get started

- **Quickstart** — create your first Reqnroll project and write your first
  scenario.

  [Reqnroll Quickstart](https://docs.reqnroll.net/latest/quickstart/index.html)

- **IDE Support overview** — what this extension does and how it fits into
  your workflow.

  [Reqnroll IDE Support](https://docs.reqnroll.net/latest/ide-support/index.html)

## Write and navigate features

- **Editing features** — syntax highlighting, diagnostics, completion,
  formatting, and defining missing steps.

  [Editing features](https://docs.reqnroll.net/latest/ide-support/editing-features/index.html)

- **Navigation** — go to a step definition, find step usages, find unused
  step definitions, and navigate to hooks.

  [Navigation features](https://docs.reqnroll.net/latest/ide-support/navigation-features/index.html)

## Configure and troubleshoot

- **Settings** — the `reqnroll.*` settings this extension contributes,
  including the `reqnroll.trace.server` log level.

  [Settings](https://docs.reqnroll.net/latest/ide-support/settings.html)

- **Troubleshooting** — common issues and how to diagnose them.

  [Troubleshooting](https://docs.reqnroll.net/latest/ide-support/troubleshooting.html)

> **Tip:** open a `.feature` file to see the extension in action. If a step
> has no matching binding yet, use the **Define Steps** quick fix to
> scaffold it.
