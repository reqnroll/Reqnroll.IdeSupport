# Reqnroll Extension for Visual Studio (Preview)

Gherkin and [Reqnroll](https://reqnroll.net) support for Visual Studio 2022 and 2026: syntax highlighting, navigation, completion, diagnostics and more for your `.feature` files and the C# step definitions behind them.

> **Preview — we want your feedback.**
> This is the new, consolidated **Reqnroll IDE Support**: one shared language server with a native extension for **Visual Studio**, **VS Code** and **Rider**, replacing the separate legacy extensions. It is in a preview period and we would like to hear how it works for you.
>
> * If you hit a severe problem, the earlier **Reqnroll.VisualStudio** extension is still available: you can disable this one and switch back at any time. Only keep one of the two enabled.
> * Please report bugs and ideas on [GitHub Issues](https://github.com/reqnroll/Reqnroll.IdeSupport/issues). Include your Visual Studio and extension versions and, if you can, the log files.
> * For how to locate the logs and turn up the log level, see [Troubleshooting](https://github.com/reqnroll/Reqnroll.IdeSupport/blob/main/docs/site/ide-support/troubleshooting.md#where-are-the-logs-and-how-do-i-change-the-log-level).

## Features

* Syntax highlighting for Gherkin feature files
* Errors and warnings for Gherkin syntax and for steps that have no matching step definition (or more than one)
* Keyword, step and tag completion
* Document and table formatting
* Comment / uncomment
* Code folding
* Go to step definition and hook navigation
* Find step definition usages and find unused step definitions
* Define missing steps from a quick fix
* Rename a step across feature files and step definitions
* CodeLens with step usage counts and hook matches, and Run / Debug on scenarios
* Inlay hints showing the step definition a step is bound to
* New Reqnroll project and item templates

See the [feature overview](https://github.com/reqnroll/Reqnroll.IdeSupport/blob/main/docs/site/ide-support/feature-overview.md) for what is available in each IDE.
