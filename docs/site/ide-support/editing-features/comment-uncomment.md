# Comment / Uncomment

The standard comment-toggle shortcut (`Ctrl+/` on Windows/Linux, `Cmd+/` on
macOS, or your IDE's configured equivalent) toggles `#` comments on the
selected line(s) in a `.feature` file. This works the same way in Visual
Studio, VS Code, and Rider.
